How to get an access token
  1. Sign in to GitHub with the shop's account and open New fine-grained token.
  2. Name it Giftoria admin and choose an expiry date.
  3. Under Repository access, choose Only select repositories and select giftoria-atelier and giftoria-orders.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Select Generate token, copy it and paste it above.

Keep the token private. Anyone who has it can change the website. If it is lost or shared, delete it on GitHub and create a new one.

Advance payment

With any advance below 100%, customers pay the rest after you send them a photo of the finished order, before it is sent. The checkout, cart and WhatsApp messages show the amounts automatically.

Why 50%: most shoppers in Pakistan still prefer cash on delivery because they worry about paying a shop they do not know yet. Half now covers your materials, and the photo before the rest shows them their order is real.

Deliveries are booked on inDrive within Multan. Customers pay the rider's fare; it is not added to the order total.

Payment methods

Customers see every Active method at checkout, with a Copy button, and upload their payment screenshot there. Switch a method to Inactive to hide it without deleting it. Methods without an account number are not shown.
